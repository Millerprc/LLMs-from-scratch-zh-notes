## 🙏 致谢原作者

这个仓库 99% 的功劳归于 [Sebastian Raschka](https://sebastianraschka.com/)。

- 原仓库: <https://github.com/rasbt/LLMs-from-scratch>
- 原书: [Build a Large Language Model (From Scratch)](http://mng.bz/orYv) — Manning, ISBN 9781633437166
- 许可证: [Apache 2.0](LLMs-from-scratch-zh/LICENSE.txt)

我做的工作只有两件:

1. 把代码注释 / README 翻成中文(在原版基础上,见 `LLMs-from-scratch-zh/`)
2. 跟着书一步步搭出来,顺手记了一份 HTML 笔记(见 `LLM学习笔记/`)

强烈建议英文 OK 的同学去读原版 —— 作者把每一步"为什么这么做"讲得非常清楚。我这版只是方便自己啃。
